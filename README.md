# fromCursor

Next.js проект (структура как у [keyToDrive](https://github.com/Mozzz-y/keyToDrive)), запускается через bun.

## Запуск

```bash
bun install
bun run dev
```

Откройте [http://127.0.0.1:3000](http://127.0.0.1:3000).

## Страницы (визуальная оболочка)

| URL | Экран |
| --- | --- |
| `/` | Загрузка фото |
| `/create-task` | Создание задачи |
| `/result/success` | Результат — вся техника найдена |
| `/result/missing` | Результат — техника не найдена |
| `/result/processing` | Результат — обработка снимка |
| `/result/error` | Результат — ошибка обработки |
| `/results` | Результаты (видео и учёт техники) |
